Sports Medicine & Anti-Doping Intelligence Platform
A full-stack biomarker monitoring system for sports medicine use cases. Lab reports are ingested through an OCR pipeline, biomarker values are analyzed using Isolation Forest for anomaly detection, and risk levels are assigned by a Random Forest classifier. Results stream live to a React dashboard over WebSockets, with an explainability layer that surfaces the top contributing biomarkers for each flag.
  • OCR pipeline for automated lab report ingestion and field extraction
  • Isolation Forest anomaly detection across multi-dimensional biomarker data
  • Random Forest risk classifier with feature importance explanations
  • Real-time WebSocket updates to React dashboard — no page refresh
  • FastAPI + Node.js backend, SQLite + Prisma ORM data layer
